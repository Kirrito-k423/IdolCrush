安装扩展

  1. 下载上方压缩包，并解压到一个准备长期保留的文件夹。
  2. 在 Chrome 地址栏输入 chrome://extensions，或在 Edge 地址栏输入 edge://extensions。
  3. 打开「开发者模式」，选择「加载已解压的扩展程序」，选择刚才解压后的文件夹。
  4. 刷新 IDOLCRUSH 页面，在视频列表中选择「顺序播放」或「随机播放」。

扩展只监听播放器的结束事件，不读取 B 站账号或 Cookie。

登录与画质

在同一个浏览器中登录 B 站后，返回放映厅并选择「登录后刷新」。登录状态由 B 站和浏览器保存。可用画质取决于视频、账号权限和 B 站播放器。

如果嵌入播放器仍提示登录，可以选择「在哔哩哔哩观看」，在 B 站页面使用已登录的会话。
